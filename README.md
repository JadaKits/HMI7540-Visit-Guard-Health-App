# HMI7540-Visit-Guard-Health-App
Home Visit Scheduling App

## Project Description
This project is a heatlhcare appointment scheduling application developed to allow clients to schedule home visits through an app-based system.

## Features
- Name Validation
- Date of Birth Validation
- Case Manager Selection
- Appointment Time Selection
- Appointment Confirmation
- Automated Confirmation Messages

## Tools Used
  - Python
  - GitHub
  - Process Flow Diagram
 
## Purpose
The purpose of this project is to imporve the efficiency of the appointment sceduling process by reducing scheduling errors, validating client information and simplyfying communication between patients and case managers through an automated application.
